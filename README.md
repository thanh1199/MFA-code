# 🔐 MFAコード発番くん v2.0

Salesforce MFA確認コードを一括発番するWebツールです。
**OAuth 2.0 認可コードフロー**対応で、SalesforceのMFA認証画面を経由してログインできます。

---

## 📋 概要

| 項目 | 内容 |
|------|------|
| ツール名 | MFAコード発番くん v2.0 |
| 用途 | Salesforce MFA確認コード一括発番 |
| 認証方式 | **OAuth 2.0 認可コードフロー**（MFA対応） |
| アーキテクチャ | Node.js + Express + jsforce |
| 出力 | CSV / 画面表示 / Teams通知 |

---

## 🏗️ 前提条件

- **Node.js 18+**（https://nodejs.org/ からLTS版をインストール）
- **Salesforce 管理者権限**
- **Salesforce 接続アプリケーション**（後述の手順で作成）

## 🔧 Salesforce 接続アプリケーション作成手順

### ⚠️ これが最も重要なセットアップです

1. Salesforce にシステム管理者でログイン
2. **設定** → 検索ボックスで「**アプリケーションマネージャ**」を検索 → クリック
3. 右上の「**新規接続アプリケーション**」をクリック
4. 以下を入力：

| 項目 | 値 |
|------|-----|
| 接続アプリケーション名 | `MFAコード発番くん` |
| API参照名 | `MFA_Code_Generator` |
| 取引先責任者メール | あなたのメールアドレス |

5. 「**OAuth設定の有効化**」にチェック ✓
6. 以下を設定：

| 項目 | 値 |
|------|-----|
| コールバックURL | `http://localhost:3000/oauth/callback` |
| 選択したOAuthスコープ | 下記3つを追加 |

**追加するOAuthスコープ：**
- `APIを使用してユーザデータを管理 (api)`
- `フルアクセス (full)`
- `いつでもリクエストを実行 (refresh_token, offline_access)`

7. 「**保存**」をクリック
8. 「**コンシューマの詳細を管理**」をクリック → MFA認証を完了
9. 表示される **コンシューマキー** と **コンシューマシークレット** をメモ
10. `.env` ファイルに設定（下記参照）

---

## 🚀 セットアップ手順

### 方法A：バッチファイル（推奨）

1. ZIPファイルを解凍
2. `初回セットアップ.bat` をダブルクリック
3. `.env` ファイルをメモ帳で開いて編集：

```env
SF_LOGIN_URL=https://login.salesforce.com
SF_CLIENT_ID=ここにコンシューマキーを貼り付け
SF_CLIENT_SECRET=ここにコンシューマシークレットを貼り付け
SF_CALLBACK_URL=http://localhost:3000/oauth/callback
```

4. `起動.bat` をダブルクリック

### 方法B：コマンドライン

```bash
cd MFAコード発番くん
npm install
cp .env.example .env    # .envを編集
npm start
```

---

## ⚠️ 重要：server.jsを直接ダブルクリックしないでください

`server.js` をダブルクリックすると **Windows Script Host エラー** が発生します。
必ず `起動.bat` をダブルクリックするか、コマンドプロンプトから `npm start` で起動してください。

## 📖 使用手順

### Step 1：ログイン
1. ブラウザで `http://localhost:3000` を開く（自動で開きます）
2. 接続先を選択（本番 / Sandbox）
3. 「**Salesforceにログイン**」ボタンをクリック
4. Salesforceのログイン画面で **ID/パスワード** を入力
5. **MFA認証**（Authenticator承認 / メール確認コード等）を完了
6. 「許可」をクリックしてアプリへ戻る

### Step 2：ユーザ検索
1. 検索条件を入力
2. 「検索」ボタンをクリック
3. 対象ユーザをチェックボックスで選択

### Step 3：コード発番
1. 有効期限を選択（1h / 4h / 8h / 12h / 24h）
2. 「発番実行」→「実行する」で一括発番

### Step 4：結果確認
1. 結果テーブルで確認コード・ステータスを確認
2. 「CSV出力」「Teams通知」で結果を共有

## 🔍 トラブルシューティング

| 症状 | 対処 |
|------|------|
| server.jsダブルクリックでWSHエラー | `起動.bat` を使ってください |
| ログイン後に元の画面に戻らない | コールバックURLが `.env` と接続アプリで一致しているか確認 |
| 「invalid_client_id」エラー | `.env` の SF_CLIENT_ID を確認 |
| 検索結果が0件 | WHERE句の構文確認。IsActive=true が自動付与されます |
| 「INVALID_SESSION_ID」エラー | セッション切れです。再ログインしてください |
